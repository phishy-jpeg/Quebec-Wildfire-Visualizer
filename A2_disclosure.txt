Lane: Bring your own agent (Blue) 
Tool Used: Github Copilot in VS code 

How it was used: For this assignment I used AI to mainly help with JS logic and with styling my page. 
The Python notebooks were written either by me or taken from the course labs, with a little bit of help for syntax errors. 

To go more in depth I first wrote the layout of my website in HTMl, meaning creating the header, where the map went; the basic elements on the page. 
I then started with the javascript. The first part was drawing the Quebec border on the map. This part was done without AI and just through the instructions in class and with online resources. 
The next part was trickier. I had to create the database and serve vector tiles. I first created a PostgreSQl database, using QGIS, and then I asked AI for help on how to create the vector tiles. 
This part was done mostly outside of VS code, so I mostly asked for steps and advice on which tool to use for the vector tiles (Martin). 
After this I had to add the vector tiles to the map. I had AI write the addition of this layer to the map in the js file (turns out it was only about 4 lines). 
Next was creating the year filters. I instructed the AI on what I wanted (drop down, ability to choose multiple years, etc) and had the AI write the code to do this. 
Finally, I had the AI help style the page, as I am terrible at making things look nice. I asked for a simple but nice lookout page, and the fist iteration looked good so I stuck with it, but made small tweaks. 

After each AI prompt, where the machine was working directly on my file, I read the code to see how the logic work, and tested the website to make sure it was acting as I wanted. 
There were many prompts I rejected for either not being what I wanted usually because the AI added unneseccary features. 

In summary, AI was used to as either a guide in processes I didn't know about and that had limited or confusing online resource (creating vector tiles)
OR
To write the monotonous code.
